# Contributing

Feedback, fixes, new features, documentation, and dashboard ideas are welcome. If you have built something useful for your own installation, please consider sharing a version others can configure for their homes.

- Open a GitHub issue to describe a problem or propose an idea.
- Open a pull request for a change you would like to contribute. Explain what it does and how another user can configure or use it.
- Keep installation-specific details out of contributions: no credentials, tokens, device serial numbers, site identifiers, energy exports, household records, roof maps, or screenshots of your own panels. Use placeholders or synthetic examples where an example is needed.
- Check the files in your commit before opening a pull request. Git ignore rules do not remove private data that was already committed.

The [installation guide](docs/installation.md) and [agent guidance](AGENTS.md) explain the project setup and privacy conventions. Contributions are shared under the project's [MIT License](LICENSE).
